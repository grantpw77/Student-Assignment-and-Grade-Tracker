# Student Assignment and Grade Tracker

## Project Overview
This project is a Python application designed to help college students keep track of their assignments, grades, and deadlines. The goal is to make it easier for students to stay organized and manage their coursework.

## Intended Users
This program is intended for college students who want a simple way to organize assignments and monitor their academic progress.

## Planned Features
- Add, edit, and delete assignments.
- Set due dates for assignments.
- Mark assignments as completed.
- Organize assignments by class.
- Record grades and calculate averages.
- View upcoming deadlines.

## Technologies
- Python
- Tkinter for the graphical interface
- SQLite for storing information

## Current Project Status
Sprint 1: Initial project setup, research, and planning.

## Future Development
The first version will focus on entering and viewing assignments. Additional features, such as grade calculations and a graphical interface, will be developed as the project progresses.
